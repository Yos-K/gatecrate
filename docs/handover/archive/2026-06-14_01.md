## 判断の根拠

- **Gap 1 を「android-jvm に kotlinc 追加」で実装した理由**: 既存の「Android SDK 不要・JVM 直接実行」
  方針（Gradle/AGP 非依存）を維持できる。kotlin アダプタを AGP 対応に拡張する案より、純ロジック層の
  変異という本来目的に最短で当たる。`.kt` 不在時は kotlinc を取得せず従来の Java 限定挙動と完全一致＝既存消費者ゼロ影響。
- **共有ヘルパーに集約した理由**: 混在コンパイルを2スクリプトに二重実装するとドリフトする（= kit が
  防ごうとしている当のもの）。既存の `build-release-aab.sh`→`android-dependency-env.sh` の sourced 流儀に倣う。
- **Gap 2 を repository variables 経由にした理由**: harness.config.sh は CI の `if:`/sdkmanager から
  参照できない。mutation.yml の `vars.MUTATION_THRESHOLD` 流儀に合わせ、未設定なら install も assert もスキップ。
- **実走スモークを行った理由**: lint だけでは「kotlinc が実際に混在コンパイルし PITest が変異できるか」を
  保証できない。実際にスモークで `src/test/java` 不在時の `find` 異常終了（Kotlin専用プロジェクトの実バグ）を検出し、dir ガードで修正した。

## 注意事項

- ローカルではフル AGP/NDK ビルドは不能（Android SDK/NDK 非搭載）。CI 依存。
- kotlinc/CMake/NDK の版は `externalNativeBuild` の宣言と CI install を**一致**させること（ズレると失敗 or fallback）。
- PITest は Kotlin 生成バイトコードにも変異を作るため、複雑な Kotlin では等価変異でスコアが下がりうる
  （`EXCLUDED_CLASSES` で調整 or Arcmutate Kotlin プラグイン検討）。
