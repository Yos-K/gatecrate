  [Harness](https://www.harness.io/) と同ドメインで商標近接。→ 「品質ゲートの crate（キット）」を表す

## 判断の根拠

- **`gatecrate` を選んだ理由**: GitHub 同名0件で発見性◎。「品質ゲートの crate（箱/キット）」という中身そのもの。
  crate は対応スタックの Rust も連想。「harness」の意味乗っ取り問題から完全に離脱できる。
- **`harness.config.sh` / `harness_kit_version` を据え置いた理由**: これらはブランド名ではなく、vendoring 済み
  消費者の CI 配線・sync-manifest スキーマが依存する**契約**。改名すると既存消費者を破壊する。スコープ「中」
  （互換性配慮）と整合。ブランド一貫性より後方互換を優先。
